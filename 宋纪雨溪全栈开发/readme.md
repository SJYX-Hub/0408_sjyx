## 技术栈

- 前端：frontend/，原生 HTML、CSS、JavaScript
- 后端：backend/，Node.js + Express，RESTful + MVC，端口 8325
- 数据库：MySQL

## 目录结构

```
frontend/          前端页面
  css/             样式
  js/              脚本
  images/          图片
  fonts/           图标字体
backend/           后端服务
  config/          数据库配置
  controllers/     控制器
  models/          数据模型
  routes/          路由
  app.js           入口
```

## 运行

双击根目录的 start.bat，然后访问 http://localhost:8325

数据库连接信息写在 backend/.env，该文件不提交到仓库。
